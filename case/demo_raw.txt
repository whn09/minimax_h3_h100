# The SAME two cases as demo_ir.txt, written the way a caller naturally writes them: one sentence of
# Chinese, no sections, no labels, no speaker IDs. This is the "before" side of every comparison in
# PROMPT_IR.md -- feed this file and demo_ir.txt to the same server at the same seed, resolution,
# frame count and step count, and the only variable is the prompt.
#
# THE POINT IS THAT THIS IS NOT MERELY A SHORT PROMPT, IT IS AN OUT-OF-DISTRIBUTION ONE. SGLang hands
# whatever you send to Qwen3-VL verbatim (presentation.py:109 -- no chat template, no rewriter), while
# MiniMax's product first expands the request through H3-Context-IR, a hosted multi-stage rewriter the
# open release excludes. The model was trained on the expanded form. So a prompt like the lines below
# is not a light request, it is the wrong shape, and what comes back is the model guessing at the 40-odd
# decisions the IR would have made explicitly -- which is exactly how a static sign ends up being
# written on camera and a spoken line ends up as babble.
#
# Synthetic, like demo_ir.txt: the prompts these were derived from were a customer's and are not in
# this repo. Same filename convention, so `scripts/sglang_case.py case=... task=...` works unchanged.
# `scripts/minimax_api.py ir --case case/demo_raw.txt --task t2va` sends one of these to the official
# compiler and prints the IR it returns, which is the cheapest way to see the gap for yourself.
